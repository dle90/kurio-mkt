# Phase A image specs — Canva-ready

**Build target:** all 4 images by May 11 (Sunday) so cells launch May 12 (Monday).
**Tool:** Canva Pro (or any equivalent — Figma, Photoshop). Specs below assume Canva.
**Total time estimate:** 3–4 hours by one designer / marketer-fluent person for all 4 images.

---

## One-time setup (do this first, before image #1)

In Canva, set up a **Kurio Brand Kit**:

- **Logo:** upload current Kurio logo files (light + dark variants).
- **Brand colors:** add Kurio's primary + secondary hex codes.
- **Brand fonts:** upload or pick web equivalents for the headline + body fonts Kurio uses.
- **Mascot art:** upload Kurimon mascot illustrations (multiple poses if available).
- **Standard badge templates** (build once, reuse across all 4 ads):
  - "3K/NGÀY" badge — circular or shield, Kurio brand color, white text
  - "Ưu đãi 100 suất" or current promo badge
  - Logo lock-up (logo + tagline)

This is a 30–45 min upfront task. Saves time on every subsequent ad. Skip if Kurio already has a Canva Brand Kit set up.

---

## Format conventions

**Dynamic-image cells (A2, A3, A4)** — Meta auto-mixes 3+ image variants × 3+ headline variants × 2+ body variants.
You produce the **base image** in 3 ratios — no text on the image, or only minimal corner badges. Meta layers headline/title/body/CTA from the asset_feed_spec.

| Ratio | Pixels | Used in |
|---|---|---|
| 1:1 | 1080 × 1080 | Feed (FB + IG) |
| 4:5 | 1080 × 1350 | Feed (mobile-optimized) |
| 9:16 | 1080 × 1920 | Stories + Reels |

**Photo cells (A5)** — single image, text overlay is OK / expected. Same 3 ratios.

**Safe zones (always leave clear):**
- Top 12% — Meta sometimes overlays profile / sponsored label
- Bottom 18% — feed CTA button
- For 9:16 (Stories): top 14% + bottom 20% are reserved by IG UI

## Cell A2 — HCM lớp 5 → Trần Đại Nghĩa (dynamic-image)

### Photo brief

**Subject:** Vietnamese mother + daughter (~10–11 years old, lớp 5 age) studying together at a home desk. Mother gently engaged, not anxious. Daughter using a tablet (showing math content if possible) with an open notebook beside it.

**Mood:** warm, calm, focused. Afternoon natural light. Domestic, not classroom.

**Avoid:**
- Classroom / chalkboard imagery
- Stock-photo "perfect smile to camera" — the kid should be looking at the tablet, not at us
- Crying / stressed kids (anti-Kurio vibe)
- Visibly Western or non-Vietnamese-looking family
- Other branded apps visible on the tablet

**Stock search keywords (Canva, Vecteezy, Shutterstock):**
- "Vietnamese mother daughter studying tablet"
- "Asian student lớp 5 homework"
- "Vietnamese family at home study"
- "Asian girl using tablet with parent"

If Canva built-in stock doesn't return Vietnamese-looking results, buy from **Vecteezy** or **Shutterstock VN** — single-photo licenses ~$10–25 each.

## Cell A4 — End-of-year report card (dynamic-image)

### Photo brief

**Subject:** A Vietnamese **giấy khen** (school certificate) or report card prominently visible — held by parent / on a table — with hands or partial figure of parent + child examining it. The 7-điểm Toán is the implicit star but doesn't need to be visually called out (the headline does that work).

**This is the trickiest of the 4 — giấy khen is culturally specific and stock libraries are thin.**

**Three options, ranked by speed:**

**Option 1 (fastest, ~30 min):** Canva mockup
- Use Canva's "certificate" templates → restyle into a Vietnamese-school report card or giấy khen
- Lay it on a wooden desk background
- Add a partial hand / tablet beside it
- Vietnamese text on the cert: realistic-looking row "Toán: 7" prominently
- Free + immediate

**Option 2 (medium, ~1 hour + cost):** Real photo
- Anyone in your team with a primary-school kid: photograph the actual giấy khen + tablet on a desk; phone camera + good light is enough
- Most authentic option

**Option 3 (slowest, $20–40):** Stock + Photoshop
- Buy a "report card mockup" or "certificate flat lay" stock image from Shutterstock; Photoshop a Vietnamese-style header + grades
- Risk: looks generic if not done well

**Recommend Option 1 for Phase A scout test. If A4 wins, upgrade to Option 2 for scale-up.**

**Avoid:**
- US/Western-style report cards with letter grades (A-F)
- AI-generated giấy khen — Vietnamese text rendering will mangle the diacritics

### Layout (1:1)

```
+---------------------------------------------+
|  [SAFE ZONE]                                |
|                                             |
|                                  [BADGE]    |  ← top-right
|                                  HÈ 2026    |
|                                  +2-3 điểm  |
|                                             |
|                                             |
|         [Giấy khen / report card            |
|          on desk; "Toán: 7" visible]        |
|                                             |
|         [Hand or partial parent figure]     |
|                                             |
|                                             |
|  [Logo lock-up]                             |  ← bottom-left
|  [SAFE ZONE]                                |
+---------------------------------------------+
```

**Text on image:**
- Top-right badge: `HÈ 2026 · TĂNG 2-3 ĐIỂM TOÁN`
- The "7" on the report card itself in red ink — visual that ties to the headline
- Bottom-left: Kurio logo

### Variants

1. Giấy khen close-up (Option 1 mockup)
2. Same but with kid's hand resting near the cert (slight emotional weight)
3. Wider shot showing parent + cert on desk

## Cell A5 — Anti-học-thêm scout (photo format, text-heavy)

This is the only cell where text on the image is expected. The headline is part of the visual.

### Photo brief

**Subject:** Kid (lớp 1–lớp 5 age) at home with a tablet, focused. Mother in soft background — working at laptop, in kitchen, or simply nearby. **Calm domestic** vibe. Living room or bedroom, not desk-centric.

**Why this composition:** The angle is "home-based learning replaces tutoring center." Visual must say "home + relaxed" — the opposite of stressed tutoring.

**Stock search keywords:**
- "Vietnamese child tablet at home mother background"
- "Asian kid using learning app at home"
- "Vietnamese family home learning living room"

**Avoid:**
- Desk + textbooks (looks like homework, not anti-tutoring)
- Empty classroom (we want the *contrast* to classroom, not the classroom itself)
- Multiple kids — single child + parent reads as testimonial

### Layout (1:1)

```
+---------------------------------------------+
|  [SAFE ZONE]                                |
|                                             |
|  CẤM DẠY THÊM RỒI —                        |  ← headline, large
|  HÈ NÀY CON HỌC TOÁN                        |     bold, top 35%
|  Ở ĐÂU?                                    |     of frame
|                                             |
|                                             |
|         [PHOTO: kid w/ tablet,              |
|          mom in soft background]            |
|                                  [BADGE]    |  ← bottom-right
|                                  3K/NGÀY    |
|                                             |
|  [Logo lock-up bottom-left]                 |
|  [SAFE ZONE]                                |
+---------------------------------------------+
```

**Text hierarchy:**
- Headline: **CẤM DẠY THÊM RỒI — HÈ NÀY CON HỌC TOÁN Ở ĐÂU?** (top 35% of frame, bold, dark text on light gradient overlay so it's legible over photo)
- Sub-line (smaller, below headline, optional): "Mẹ nào cũng đang lo — đến đây xem giải pháp"
- Bottom-right badge: `3K/NGÀY`
- Bottom-left: logo

**Font hierarchy (Canva):**
- Headline: heavy/bold sans (Be Vietnam Pro Bold, Bebas Neue VN, or whatever Kurio brand kit specifies)
- Sub-line: medium weight, ~50% size of headline
- Badge: bold sans, white on Kurio brand color

### Variants

1. Headline option 1: `CẤM DẠY THÊM RỒI — HÈ NÀY CON HỌC TOÁN Ở ĐÂU?`
2. Headline option 2: `KHÔNG CÒN GIA SƯ, KHÔNG CÒN TRUNG TÂM — HỌC TOÁN HÈ KIỂU MỚI`
3. Headline option 3: `BỎ HỌC THÊM 3 THÁNG — CON VẪN GIỎI TOÁN HƠN HẲN`

Different headlines × same photo = clean A/B on which framing performs.

### Sensitive note

**Comms / legal must approve the headline wording before this image is finalized.** "Cấm dạy thêm" specifically references current MoE policy — wording should read as parent observation, not regulation citation. If comms wants softer wording, headline option 2 ("Không còn gia sư, không còn trung tâm…") is safer and tests the same psychological angle.

## Stock photo procurement note

Single-photo licenses on Vecteezy / Shutterstock VN: ~$10–25 each. Budget ~$60–100 for the whole batch (some photos used in multiple ratios). Canva Pro built-in stock may be enough for A2/A3/A5 — check there first; only buy externally if results are too generic-Asian (i.e. read as Korean/Chinese, not Vietnamese).

## What I cannot judge from here

- **Whether Kurio's actual brand colors / fonts feel right** with the layouts above. Designer should match brand kit and adjust.
- **Whether the giấy khen mockup (A4 Option 1) looks authentic enough.** If it looks fake, viewers will discount the whole ad — A4 should fall back to Option 2 (real photo).
- **Whether the headline text on A5 is legible at small mobile sizes.** Test at 375px-wide phone preview before launch.
